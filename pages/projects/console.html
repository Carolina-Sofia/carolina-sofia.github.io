console.log(myFeelings)

Project Overview

console.log(myFeelings) is a Node.js web application designed to promote daily self-reflection by prompting users with questions about their day and saving their short answers. I developed this project to deepen my understanding of Express, EJS templating, and session management. The app is lightweight, focusing on simplicity and personal introspection rather than complex data storage.

Key highlights:

  • Daily Reflection Flow – A minimal, question-driven interface encouraging quick, mindful responses.
  • Session-based Data – Uses express-session to store answers in memory and ensure each user only sees their own data.
  • Randomized Prompts – A pool of questions for variety and inspiration.

Skills Used in This Project

Front-End Development
  • HTML5 & CSS3
  • Bootstrap for basic responsiveness
  • EJS Templates
Back-End Development
  • Node.js & Express
  • Session Management (express-session)
  • RESTful Routing
Additional Tools & Concepts
  • JavaScript (ES6+)
  • DOM Manipulation & Fetch API

Key Features

  • Three-Question Limit: Users can only answer three prompts per day (or per session), helping keep reflections concise.
  • Randomized Prompts: Each page load serves up a random question from a curated list, ensuring variety.
  • Private Session Data: Answers are stored in the user’s Express session, never shared or persisted in a database.
  • Simple Edit Flow: Each question can be viewed and edited on a dedicated page (post.ejs).

Basic User Flow

console.log(myFeelings) focuses on quick daily journaling:

  1. Landing Page: Introduces the concept of daily reflection, with a call-to-action button (“Let’s Go”) to start.
  2. Questions Page: Displays a random question; user types an answer, which is stored in the session.
  3. Review List: The user can see their answered questions, each linked to its own detail page.
  4. Detail Page: Allows editing an individual answer, with changes saved back into the session.

My Contributions

  • Complete Node/Express Setup: Handling routing, sessions, and EJS for dynamic pages.
  • Front-End Logic: JavaScript for random question selection, form submissions, and dynamic updates.
  • Responsive Design: Ensuring a clean layout on both desktop and mobile using Bootstrap and custom CSS.
  • Error Handling & Validation: Basic checks (e.g., empty answers, session existence) to ensure a smooth user experience.

Challenges & Learnings

  • Session-Based Data Management: Gained practical experience with express-session, ensuring each user’s data stayed private.
  • Front-End & Back-End Coordination: Learned to handle fetch calls from the client side to POST answers, then reload the page to show updated session data.
  • Responsive Layout: Using Bootstrap’s grid system to ensure the UI was cohesive across different screen sizes.

Project Impact

  • Personal Growth: Sharpened my Node.js and Express skills, along with EJS templating and session handling.
  • Mindful Habit: Encouraged quick, daily journaling, fostering a habit of self-awareness.
  • Scalable Learning: The codebase can be extended easily to add login, persistent DB storage, or more advanced features.
